# RouteStress UI registry

## Product shell

The shell uses a Quiet Civic foundation with a light blue gray canvas, white panels, royal blue actions, and restrained teal and amber status colors. Cards use 16 pixel rounding and a light shadow. The sidebar collapses to an icon rail below 900 pixels, then the workspace stacks into one column below 560 pixels.

## Shared patterns

Status badges always pair a symbol with text. The route line uses numbered or checked nodes and labeled steps, so state remains understandable without color. The scenario control stages a change in local component state and uses a visible review warning before any future route mutation. Theme values are semantic custom properties in `app/globals.css` and switch through the `data-theme` attribute.
